# Guidelines

Reusable coding guidelines that can be imported into any project's `CLAUDE.md` with `@~/.claude/guidelines/<file>.md`. The file is loaded fresh each session, so it stays in sync with this repo without copying.

| File | Use |
|---|---|
| `guidelines/python.md` | Python coding guidelines — exception handling, async, generators |
| `guidelines/php.md` | PHP / Laravel / Pest coding guidelines — DDD layering, immutability, factory & test conventions |

Add new guidelines here as you encounter patterns worth sharing across projects (e.g. `guidelines/laravel.md`, `guidelines/react.md`).
